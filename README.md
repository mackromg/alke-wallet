# Proyecto Final Módulo 2 - Alke Wallet

¡Hola! Este es mi proyecto final integrador para el Módulo 2. 

Se trata de "Alke Wallet", una simulación de una billetera web donde apliqué todo lo que fuimos viendo en estas semanas. La app permite revisar el saldo, simular depósitos y retiros, guardar contactos nuevos y transferir plata (todo esto reflejándose en un historial de movimientos).

## ¿Qué tecnologías usé?
* **HTML5 y CSS3:** Para la estructura base y los estilos.
* **Bootstrap 5:** Me salvó la vida para hacer que sea responsivo rápido y usar tarjetas/botones listos.
* **JavaScript y jQuery:** Acá está toda la lógica. Lo usé para darle vida a los botones, calcular los saldos, validar los formularios y guardar los datos en el `localStorage` (así no se borra todo si recargas la página).
* **jQuery UI:** Lo metí como un extra para armar el autocompletado del buscador de contactos.

## ¿Cómo probarlo en tu PC?
Si quieres darle una mirada al código funcionando:
1. Abre tu terminal y clona este repo: 
   `git clone https://github.com/tu-usuario/alke-wallet.git`
2. Entra a la carpeta del proyecto.
3. Haz doble clic en el archivo `index.html` para abrirlo en tu navegador (Chrome, Edge, etc.).

*(Dato: en la pantalla de login puedes poner cualquier correo, la clave de prueba es **1234**).*
